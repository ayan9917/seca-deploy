# Dating Proposal App v2 ❤️

Flow:
1. Enter your name and their name.
2. Show a romantic proposal with attractive YES/NO cards.
3. The NO button moves away when approached/clicked/touched.
4. YES opens a date planner.
5. Choose date, time and optional place.
6. Show a final invitation card with all details.

Run by opening index.html in Chrome or Edge.
No backend or external libraries are required.
